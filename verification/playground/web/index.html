Vox playground

Demonstrations

Vox is OxCaml with refinement types checked by Z3 at compile time, erased ghost code and affine ghost ownership. Pick an example, edit it and check it. Everything runs in your browser: the Vox compiler's front end and verifier are compiled to JavaScript with js_of_ocaml, and Z3 is compiled to WebAssembly. Nothing is sent to a server.
