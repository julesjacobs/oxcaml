Vox

Refinement types, ghost code and ghost ownership for OxCaml

Vox is a fork of the OxCaml compiler that checks specifications at compile time. A type can carry a refinement, {r : int | lo <= r && r <= hi}, and the compiler turns each function's refinements into verification conditions that Z3 must prove. Proofs are written as ghost code (ghost arguments, ghost blocks and lemmas), which the compiler checks and then erases before code generation. Ghost tokens are affine, enforced by OxCaml's uniqueness modes; a token stands for ownership of mutable state, which is how the demos specify mutable cells, hash tables and communication between domains.

A proof holds only if the checker, Z3 and a small set of unverified primitives are correct; what every demo trusts lists them.
